# effectnode-easy-fancy

A five-chapter, scroll-driven WebGPU experience built with Three.js, React Three Fiber and TSL — edited through the easy-fancy chat UI.

1. Download the project code.
2. Open the folder using: claude / codex / opencode / pi agent / hermes / openclaw or another harness.
3. Run the prompt "start server".
4. It opens a webpage with a chat on the left and the live preview on the right.

# What is EasyFancy?

It makes editing a fancy website easy.
